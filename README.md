Small Store Inventory Management App

App Description

The Small Store Inventory Management App is a mobile application developed using FlutterFlow and Firebase Firestore. It is designed to help small store owners manage their products and inventory records in an organized way.

Technologies Used

* FlutterFlow
* Firebase Firestore

Features
* Add Products
* Manage Product Information
* Save Product Records
* View Inventory Information

How to Access and Run the App

1. Open the app using the link below:
    https://small-store-inventory-xy3ed2.flutterflow.app
2. Open the link using a web browser.
3. Navigate through the application and use its available inventory management features.
